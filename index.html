തീയതി അക്കൗണ്ട് ഹെഡ് അക്കൗണ്ട് തരം രസീത് No (Receipt) വൗച്ചർ No (Voucher) വിശദാംശങ്ങൾ ക്രെഡിറ്റ് (Credit ₹) ഡെബിറ്റ് (Debit ₹) ബാലൻസ് (Balance ₹)

തിരഞ്ഞെടുത്ത ഫിൽട്ടറുകളിൽ ലെഡ്ജർ വിവരങ്ങൾ ലഭ്യമല്ല

രേഖകൾ ഒന്നും കണ്ടെത്തിയില്ല

സമ്പൂർണ്ണ കൗൺസിൽ റിപ്പോർട്ട്

ലൈബ്രറികൾ, പദ്ധതികൾ, ക്യാഷ് ബുക്ക് സംഗ്രഹം എന്നിവ ഉൾക്കൊള്ളുന്ന സമ്പൂർണ്ണ റിപ്പോർട്ട്.

ക്യാഷ് ബുക്ക് സ്റ്റേറ്റ്മെന്റ്

വരവ്-ചെലവ് പട്ടിക, വൗച്ചർ വിവരങ്ങൾ, ബാക്കി തുക എന്നിവയുടെ ഓഡിറ്റ് റിപ്പോർട്ട്.

അക്കൗണ്ട് ലെഡ്ജർ സ്റ്റേറ്റ്മെന്റ്

ഹെഡ് അടിസ്ഥാനത്തിലുള്ള വരവ്-ചെലവ്, ഡെബിറ്റ്, ക്രെഡിറ്റ്, ബാലൻസ് റിപ്പോർട്ട്.

ലൈബ്രറി ഡയറക്ടറി

എല്ലാ ലൈബ്രറികളുടെയും പേര്, ഗ്രേഡ്, ഫോൺ നമ്പർ, പരിശോധന വിവരങ്ങൾ.

പദ്ധതി വിനിയോഗം

അനുവദിച്ച ഫണ്ട്, വിതരണം ചെയ്ത തുക, ഗുണഭോക്ത്യ ലൈബ്രറികൾ.

ഡാറ്റാ സുരക്ഷയും ബാക്കപ്പും (Data Backup & Safety)

ഈ ആപ്ലിക്കേഷൻ നിങ്ങളുടെ കമ്പ്യൂട്ടറിലോ മൊബൈലിലോ ഓഫ്‌ലൈനായി പൂർണ്ണ സുരക്ഷിതമായി പ്രവർത്തിക്കുന്നു. നിങ്ങളുടെ ഡാറ്റ നഷ്ടപ്പെടാതിരിക്കാൻ കൃത്യമായ ഇടവേളകളിൽ ബാക്കപ്പ് ഫയൽ ഡൗൺലോഡ് ചെയ്തു സൂക്ഷിക്കുക.

JSON ബാക്കപ്പ് ഡൗൺലോഡ്

എല്ലാ വിവരങ്ങളും അടങ്ങിയ സമ്പൂർണ്ണ ബാക്കപ്പ് ഫയൽ നിങ്ങളുടെ കമ്പ്യൂട്ടറിലേക്ക് സേവ് ചെയ്യുക.

ബാക്കപ്പ് റീസ്റ്റോർ ചെയ്യുക

നേരത്തെ ഡൗൺലോഡ് ചെയ്ത ബാക്കപ്പ് ഫയൽ അപ്‌ലോഡ് ചെയ്ത് വിവരങ്ങൾ തിരികെ എടുക്കുക.

എല്ലാ വിവരങ്ങളും ശൂന്യമാക്കുക (Clear All)

ഡാറ്റാബേസിലെ വിവരങ്ങൾ മുഴുവൻ ക്ലിയർ ചെയ്ത് പുതിയ സാമ്പത്തിക വർഷം ആരംഭിക്കാൻ.

ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്യുക (Install App)

കമ്പ്യൂട്ടറിലോ ഫോണിലോ നേരിട്ട് ഉപയോഗിക്കാം

ഈ ബ്രൗസറിൽ നേരിട്ട് ഇൻസ്റ്റാൾ ചെയ്യാൻ താഴെ ക്ലിക്ക് ചെയ്യുക:

കമ്പ്യൂട്ടറിൽ (Windows / Mac PC)

1. Google Chrome അല്ലെങ്കിൽ Edge ബ്രൗസറിന്റെ വിലാസ ബാറിന്റെ (Address bar) വലതുവശത്ത് കാണുന്ന കമ്പ്യൂട്ടർ/ഡൗൺലോഡ് ഐക്കണിൽ [⊞] ക്ലിക്ക് ചെയ്യുക.

2. 'Install' അമർത്തുക. ആപ്പ് കമ്പ്യൂട്ടർ ഡെസ്ക്ടോപ്പിൽ ഐക്കണായി വരും.

Android ഫോണിൽ (Chrome)

1. മുകളിൽ വലതുവശത്തുള്ള മൂന്ന് ഡോട്ടുകളിൽ (⋮) ക്ലിക്ക് ചെയ്യുക.

2. 'Install app' അല്ലെങ്കിൽ 'Add to Home screen' തിരഞ്ഞെടുക്കുക.

iPhone / iPad (Safari)

1. താഴെയുള്ള Share ഐക്കണിൽ () ക്ലിക്ക് ചെയ്യുക.

2. താഴേക്ക് സ്ക്രോൾ ചെയ്ത് 'Add to Home Screen' നൽകുക.

താലൂക്ക് ലൈബ്രറി കൗൺസിൽ

ഔദ്യോഗിക സ്റ്റാഫ് ലോഗിൻ (Supabase SQL Security)

അഡ്മിൻ സഹായം: സ്റ്റാഫ് ലോഗിൻ എങ്ങനെ നിർമ്മിക്കാം?
  1. Supabase Dashboard → Authentication → Users തുറക്കുക.
  2. Add User → Create New User ക്ലിക്ക് ചെയ്ത് Email, Password നൽകുക (Auto Confirm User ടിക്ക് ചെയ്യുക).
  3. സുരക്ഷയ്ക്കായി Authentication → Sign In / Providers-ൽ Allow new users to sign up ഓഫ് ചെയ്യുക.

Database URL & Anon Public Key

നിങ്ങളുടെ Supabase പ്രോജക്ട് വിവരങ്ങൾ നൽകുക:

  1. supabase.com ഡാഷ്‌ബോർഡിൽ SQL Editor തുറന്ന് supabase_sql_migration.sql റൺ ചെയ്യുക.
  2. Project Settings → API തുറന്ന് Project URL ഉം anon public key ഉം താഴെ (അല്ലെങ്കിൽ config.js-ൽ) നൽകുക.
